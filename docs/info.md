## How it works

This project implements a combinational 4-bit Arithmetic Logic Unit (ALU).

The ALU accepts two 4-bit input operands, A and B, and a 3-bit operation
select signal. Based on the selected operation, the ALU performs arithmetic
or logical operations and produces a 4-bit result.

The eight supported operations are:

| OP | Operation | Function |
|----|-----------|----------|
| 000 | ADD | A + B |
| 001 | SUB | A - B |
| 010 | AND | A & B |
| 011 | OR | A \| B |
| 100 | XOR | A ^ B |
| 101 | NOT | ~A |
| 110 | Increment | A + 1 |
| 111 | Decrement | A - 1 |

The ALU also provides two status flags. The Carry output indicates the
carry/extended bit generated by arithmetic operations, while the Zero output
is asserted when the 4-bit result is zero.

The design is purely combinational and does not require a clock or reset.

## How to test

The ALU can be tested by applying values to the A, B, and OP inputs and
observing the result and status flags.

The project includes an automated cocotb testbench. It exhaustively tests all
8 operations with every possible combination of the two 4-bit operands.

This results in:

8 operations × 16 A values × 16 B values = 2048 test cases.

The testbench checks the 4-bit result, Carry flag, and Zero flag for every
test case.

## External hardware

No external hardware is required.

The design uses only the Tiny Tapeout digital I/O pins.
